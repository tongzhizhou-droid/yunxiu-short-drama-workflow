# 关键帧提取与连续性取证

需要从采用版视频抽取片尾状态、指定时间、切镜代表帧或概览联系表时读取。运行 `../scripts/extract_keyframes.py`；脚本输出 PNG、可选联系表和 `manifest.json`，自动评分只负责筛候选，采用前必须人工查看。

```powershell
python ../scripts/extract_keyframes.py --input VIDEO --output-dir OUTPUT --mode tail --tail-seconds 4 --top-k 5 --contact-sheet
```

模式：`tail` 选片尾候选，`timestamps` 按指定秒数，`scene` 按切镜候选，`uniform` 均匀概览。依赖见 `../scripts/keyframe-requirements.txt`；优先使用 Codex 工作区随附 Python，不在未授权时安装到系统全局环境。OpenCV 无法解码时先确认源文件完整可播放，转换格式须保留源件并记录可变帧率时间偏差。

尾部抽帧仍遵守工作流规则：尾部只用于确认实际状态；下一段生成参考应从候选中分别选站位帧和背景帧，不直接绑定原始尾帧。

## 按用途选择证据

- **片尾接续**：选择最靠后、同时能看清相关人物站位、道具、接触关系、动作阶段和背景关系的有效帧。
- **空间参考**：选择最清楚展示完整人物关系的画面；它不一定是最后一张有效帧。
- **动作阶段**：选择能明确显示动作进度的准确画面，例如松手、脚落地或物品交接到哪一步。
- **切镜证据**：疑似切镜点前后至少各取一帧。单张图不能证明发生了切镜。
- **人物或服装核对**：选择脸部和服装足够大、能够辨认的画面，即使它不是最合适的空间参考帧。

一张图不必承担全部用途。空间关系需要全景，而人物身份或动作细节需要近景时，应分别导出。

## 剔除或标记复核

全黑、严重模糊、严重过曝或欠曝、主体被大面积遮挡，以及两个镜头明显叠混的画面应当剔除。出现以下情况时标记人工复核：

- 眼睛、相关手部或道具看不清；
- 前景人物挡住了需要记录的关系；
- 字幕、水印或界面遮住关键证据；
- 画面靠近检测到的切镜点，或处于快速运镜中；
- 画面带有不应传递到下一镜的生成错误。

自动程序可以测量清晰度、亮度、黑白区域占比和相邻画面变化，但不能可靠判断所有人物、表情、道具和剧情事实。

## 连续性记录字段

| 字段 | 需要记录的内容 |
|---|---|
| 来源 | 视频文件名或版本、SHA256、准确时间点 |
| 人物 | 仅记录画面中可见且已确认的人物身份与服装 |
| 位置 | 左右、前后、人物间距、与场景锚点的关系 |
| 朝向 | 身体方向、头部方向、视线目标 |
| 手部与道具 | 持有人、左右手、高度、方向、是否接触 |
| 动作阶段 | 已开始、已完成或仍在进行的动作 |
| 背景 | 门、楼梯、桌、车辆、窗、地平线和光线方向等固定参照 |
| 未知项 | 画外、遮挡、模糊或存在歧义的内容 |

不能用原计划或提示词补齐未知项。如果实片与计划结尾不一致，应记录实片状态，再单独决定修复上一段还是由下一镜桥接。

## 命名建议

时间点保持机器可读，人工复核后再增加语义名称，例如：

```text
EP03_SH02_013.800s_角色A右_角色B左_包在左手.png
```

`manifest.json` 应与关键帧放在同一目录。采用图被改名或复制到其他位置时，在项目记录中写明它对应的原候选文件和时间点。
