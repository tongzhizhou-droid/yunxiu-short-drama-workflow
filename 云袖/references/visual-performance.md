# 真人审美、竖屏摄影与表演基准

资产制作和导演设计时读取。将本项目选择写入 output/制作基准.md，同场景继承同一版本，不逐卡重选风格。直接依据已有剧本制作，不开展故事开发或本地化改写。

## 情绪准确与镜头流畅是基本放行条件

从原文与前情确定每个重要节拍的“此前情绪／知情 → 具体刺激 → 对谁的第一反应 → 采取或压住的行动 → 新状态”。不能把委屈拍成单纯愤怒、把早已知情拍成首次震惊、把伪装拍成真情失控；含混处依据原文及后续行动判断，关键动机不明则标待确认。

每个镜头说明此刻为什么看这个人或物，下一镜由什么视线、动作、声音或信息触发。先让观众看见或听见刺激，再让其读懂反应；有意悬念倒置时必须随后补清因果。流畅不等于只用连续运镜：固定机位反打和必要硬切同样可用，关键是空间、动作、声音及情绪递进成立。

删旁白或压短画面时保留引发情绪的事实与足以读清的反应；重要变化允许停顿，不为速度删去犹豫、承认、接受或拒绝的转折。不能只按“很生气—很震惊—很得意”的标签排镜。技术连续但情绪跳变，同样不通过。

若项目明确制作付费卡点后的剧情，重点是兑现已建立的期待、推进后果与关系变化；承接上集的情绪和行动，不每段重新介绍人物或造一个开场钩子。按原文保留该有的高潮与余波，不为持续刺激凭空加反转，也不把每个生成段都做成集尾悬念。非此范围不套用该定位。

## 把“电影感”变成可执行设计

为每个主要场景确定：时间与天气、真实主光来源及方向、环境色与肤色关系、背景层次、材质、人物服装与环境的区分、空间锚点及行动通道。角色受同一场景光照，肤色保留自然纹理；不默认磨皮、满脸油亮、过曝轮廓光、全场浅景深或所有场景橙青调色。豪华由空间、材质和人物行为共同建立，不堆满金色装饰。

用可见特征描述摄影，不把器材品牌、IMAX、8K或“百分百还原”当质量保证。景深应让关键人脸、交接或证据可辨，脸部不因追求虚化而漂移。动作镜头需看清接触关系；关系对峙优先让观众看清受影响的人。

## 竖屏构图

默认9:16可由项目覆盖。先分配人物脸、视线、手与关键道具的位置，再选择景别；避免宽画幅站位直接挤入竖屏。过肩前景保持必要边缘，不能遮住情绪主体。多人场面用前后深度、出入画和反应组织权力，不把所有人横排在同一平面。

发行平台已知时按其当前界面安全区安排关键脸部和文字；未知则预留界面空间并标待适配，不写死通用像素值。不要求所有脸始终居中：亮相、孤立、逼迫和退让各用有意义的构图。建立空间后减少重复全景，需要距离、接触或阻拦时保留完整动作景别。

## 表演从意图出发

人物情绪提示词不得用特定颜色描述脸部、肤色、嘴唇或眼睛的变化，例如“脸色发白”“面色铁青”“嘴唇惨白”“眼睛发红”“双眼血红”。改用符合情境的简洁情绪、动作、视线和声音表现，如“惊恐地愣住、后退半步”“含泪看向对方、声音哽咽”。不将禁用词作为负面限制复制进生成正文，避免模型仍将其视觉化。此规则针对人物生理颜色与情绪描述，不禁止必要的服装、道具、场景及光线颜色；原文对白保持原语言和事实。

每个节拍用“我想让对方做什么—采用什么行动—对方如何改变我”确定表演。可用逼问、安抚、试探、掩饰、挑衅、拒绝等行动，再配简洁情绪、视线和具体行为。保留既有不拆解五官肌肉的写法。

同一威胁下，知情者可掩饰，受害者可压怒，旁观者可避开；不让全场同步震惊。反派也要争取具体东西，不全程狂笑；强者不必每句冷笑，脆弱者不必一直哭喊。强烈情绪必须有刺激与后果，幅度依题材和人物，不把克制当所有场景的唯一审美。

对白有接收对象、目的、潜台词和语义重音。听者在信息到达后反应，不能提前知道。重要停顿服务于决定、隐藏或关系变化，删除仅为“高级感”的空等。亲密戏先建立自愿互动、距离和回应；权力压迫通过空间、视线、打断与选择体现，不把接触当装饰。

## 声音与语言可信度

声音表记录角色、语言／口音、参考音色、语速范围、当前情绪、发音表和现场／画外／旁白身份。名字、地名、缩写先统一读法；不得只因有MP3就宣称音色一致。无试听能力时标“未试听”。

先完整试读或使用真实配音测时，再安排镜头。本项目新设计英文对白按每秒1.5—3词随情绪自然变化，不机械匀速；用户提供的旁白以原音频实测为准，不强行变速适配此区间；抽泣、威胁、专名和停顿另留时间，其他语言另估。记录实际声音区间，禁止用模型倍速或删词适应短卡。环境声和动作声对应空间与动作，不掩盖对白；默认不做配乐和最终混音。
