# 反馈落实与版本接续

用户要求改稿、补镜、检查穿帮、续做或处理旧新稿冲突时读取。日常顺序制作只用相关检查项，不重复加载全部历史。

## 1. 把反馈变成可核对的变化

记录用户原话、段镜／时间点、希望观众看到的结果和适用范围。先查当前稿与实际采用片；同一事项的后续纠正覆盖旧选择，不覆盖其他集。

区分：已确认长期偏好、当前项目选择、单镜修复、待验证经验。前两类分别落在通用要求与项目配置，后两类写入受影响输出和经验候选。此次整理允许改进流程结构，不等于把本剧所有参数推广成通用标准。

## 2. 先修最小范围，再检查关联

单镜问题先修该镜及两侧接点；因果或事件顺序错误才回到节拍。不要只替换镜头句子而保留相反的素材用途、轴线、站位或剧情描述。

检查六处：素材用途→轴线→前情／站位→剧情描述→逐镜动作→声音与时长。若造型变化影响旁白，列出原句、新句与待替换音频；没有明确改文授权时保留原文并报告冲突。

本地稿实质更新递增版本；同步逐段计划、自审及当前状态。平台正文另记同步版本和回读结果；视频仍保留原生成版本，除非实际产生新片。

## 3. 物理关系与表演检查

- 直播镜头：分别说明摄影机、持机者、手机屏幕、后置镜头、被拍对象的朝向；屏幕朝持机者，拍摄镜头朝现场。若只需表达直播持续，可用侧面局部并结合持机者反应；这是可选解决方法，不固定所有手机镜头。
- 距离与动作：先判断人物是否已经到位。尚未到位才写接近过程，动作所占时间与距离、步数相称；到位后的剩余对白由近景、有效反应和局部动作承载。不要把“两米、两三步、1.4秒”写成所有场景标准。
- 构图与可见性：胸上特写不能同时证明腰下手势或全身步法。选择能看到所需动作的景别，或拆为局部镜头，并维持空间方向。
- 情绪反应：以当前刺激和人物知情为依据；延续已建立表情，不无故转为惊恐。不把未剪接的长跑、等候或反复准备当成张力。
- 界面：先确定是直播、录像还是外层观看屏幕，以及目标语言。剧情不需可读界面时不强加复杂文字；界面要求按项目保存。

## 4. 以当前采用实片接续

先核对文件、版本／哈希与采用状态，再看尾部实际距离、位置、动作阶段、持物、表情和光线。文字写“刚起跑”但实片已经到近前时，下段接近前状态，不重新起跑；若该偏差改变剧情结果或动作前提，先记录冲突并修复或确认采用，不强行迁就错误实片。

从采用实片选站位／背景关键帧，逐项限定用途；不直接绑定原始尾帧。旧参考与当前起态冲突时撤下或缩小为已核验的身份／服装用途，不能继续用它控制距离和动作。

整段拒绝片与诊断帧不作为续段参考；局部受限采用必须写明可用片段与维度。未得到采用片时可做文字预案，但不能标记实片连续性通过。

## 5. 按证据关闭问题

修改后的文字复查通过，仅关闭“设计问题”。平台回读通过，仅关闭“同步问题”。新成片实际静帧、动态和声音检查完成后，才关闭对应成片问题。

同一缺陷连续两轮未解决时，保留证据，换镜头方法、简化动作或回到资产层，不堆叠否定词并无限重抽。生成前检查已有任务和授权余量；已有有效授权不重复询问，授权之外的付费动作不执行。
