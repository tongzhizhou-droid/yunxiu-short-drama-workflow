# 自审、实片验收与非剪辑交付

分镜自审与生成后验收分别读取并执行适用项。检查目的不是凑分，而是指出具体镜号／媒体时间点、观众会误解什么、如何最小修复。

## 文字自审

| 维度 | 判定问题 | 回修去向 |
|---|---|---|
| 剧情与信息覆盖 | 主体欲望与阻碍是否清楚；因果、对白和揭露有无擅改；称呼与场景行为是否符合项目设定 | 剧情／导演 |
| 节奏 | 开场是否已进入有效事件；中段是否有状态变化；反应是否增加信息；集尾是否兑现并留下具体期待 | 剧情／导演 |
| 表演 | 行动是否针对具体人；反应是否在刺激后出现；情绪是否有差异和变化而非全场模板 | 导演 |
| 审美 | 光源、肤色、服装、空间与景深是否一致；竖屏能否看清脸与关键动作；有无无目的炫技 | 美术／导演 |
| 声画时间 | 台词能否自然说完；顺序声音有无冲突；并行动作是否重复计时；证据能否读清 | 导演／声音 |
| 生成可执行性 | 单段负担是否合理；关键资产、正文限制、模型功能是否真实可用 | 资产／平台适配 |
| 连续性 | 知情、持物、接触、轴线、时间层级和跨段首尾是否成立 | 连续性／导演 |

旁白专项还须读取[取舍与时长规则](../skills/yunxiu-director/references/narration-visuals.md)：逐条查重要性、画面替代是否成立、最终保留声音覆盖与压缩后因果。原文覆盖不等于旁白逐字朗读。

每项记录证据与结论，不用“电影感十足”“完美达标”替代依据。严重问题包括错人错词、改变事实、漏关键因果、声音放不下、必要资产缺失、无法成立的动作或前后状态；须修复后才放行依赖范围。人物情绪违背原文与知情状态、刺激与反应缺失导致情绪跳变、相邻镜头令人无法理解动作或观看对象，也属于基本要求未达标，不能仅列为审美建议。其他审美改进建议不伪装成硬阻塞。结论为“通过／通过并保留非阻塞建议／需回修／待资料”，附审查版本和有效范围，不用平均分抵消致命问题。

音频切气口路线另查源文件到导出片段的时间映射、完整词句、自然呼吸、文件实测时长与试听结论，按[音频处理规则](../skills/yunxiu-director/references/narration-audio.md)执行；仅检测到静音不等于气口已校对。

## 实片检查

先确认真实源版本，按正常速度完整观看本段并试听，再定位关键处；无法播放／试听时只报告实际完成的元数据或静帧检查。静帧不能证明无闪烁、动作自然、口型同步或声音正确。

- 图像：身份、服装、肤色与光线、手与接触、道具文字、遮挡、背景稳定、闪烁和漂移；观察发生在哪一秒、是否影响剧情。
- 表演与节奏：反应对象是否明确、表情是否早于刺激、是否无信息停留、动作是否重播、承诺的关键镜头是否遗漏。
- 音频：完整对白与说话人、语言与名字发音、重复或截断、口型与声音相位、错误发声的听者、噪声和动作声来源。
- 首尾：实际起止状态及前段接点，末帧与后续必要条件；并非所有换场都需像素匹配，但时空与因果必须成立。尾部用于确认实际状态，下一段的生成参考应另从前段实片选取能表达站位或背景的连续性关键帧，不直接引用原始尾帧。
- 增强：与原片对应，实际尺寸、时长和音轨是否正确，是否引入伪影；放大不修复错词、错人或错误动作。

记录“设计时长／平台所选时长／实测时长”，差异触发内容与声音检查；接近某个秒数本身不算节奏通过。分开标记设计通过、生成完成、实片可用、增强完成、归档完成；未检项目不得写通过。重大问题先标“待修复”，处理范围服从授权。

## 交付边界与清单

交付到可供剪辑使用的独立素材，不剪接整集、不烧录字幕、不叠字合成、不配乐混音、不输出剪辑工程或宣称最终发布版。镜头间切点、声音覆盖和必要首尾余量属于制作设计，可记录给后续人员，不在本流程执行剪辑。

交付清单写在已有逐集归档记录或按需建立的 output/第XX集_交付清单.md：

1. 当前剧本与分镜版本、原文覆盖范围、自审结论。
2. 逐段视频的真实文件、版本、画幅尺寸、帧率、时长、声音状态、字节数与完整性依据；不擅自转码改变帧率。
3. 资产映射、独立声音文件及对应镜号（实际存在时），实片首尾状态，以及从前段实片选取的续段站位／背景关键帧、来源时码和使用边界。
4. 逐段是否可用、尚未检查什么、需补镜／重生成什么、准确文字或旁白等待后期事项。
5. 下一步应由谁处理及所需输入；所有必要片段尚未齐全时交付状态为“部分完成”。

项目表、分镜标题／概览、逐段JSON、平台正文必须反映同一版本和段数。旧片按旧版本记录，不能用新稿标签替它“升级”；hash匹配只证明文件对应，不证明内容质量。
