# 从导演稿到可生成素材

导演分段、平台能力变化、失败回修时读取。导演稿表达叙事目标；提交正文只保留当前模型能执行且本段必需的约束，不用堆叠形容词补偿不清楚的动作。

## 能力与分段

从实际平台记录模型、可用时长、参考类型与数量、声音及口型能力、多镜支持、首尾帧支持、画幅、分辨率、正文限制和当前费用；未知写未知。未进入平台的写稿阶段可按项目已知条件拟稿，将能力假设标在正文外。沿用已确认的内置浏览器、自由模式和自动资产偏好核验能力，不再发起已取消的模式询问。

分清三个单位：镜头是一次连续观察，节拍是关系或信息变化，生成段是一次提交。一个生成段可含多镜，但不以固定秒数或固定镜头数量拆卡。优先在完整语句、动作落点或时空转换处划界；高风险交接不能从手接触中途随意截开。

每段识别身份数、空间变化、接触动作、连续对白、精确文字、屏幕嵌套及运镜的同时负担。多角色抢话、复杂撕扯、快速换景、准确长文和穿屏运镜叠加时，保留剧情事实，拆为建立关系、关键动作、证据／反应等更清晰的单位；不删除关键动作或以成片“自动脑补”为方案。

采用已授权的小范围代表片段验证身份、光线、表演与声音；没有试生成授权则仅提供测试段方案，不擅自扣费。测试段应覆盖本集主要难点，已有可用实片能验证的直接复用。顺序续段必须等前段最终采用实片完成：尾部用于确认实际状态，再从实片选取能表达站位或背景的关键帧给下一段分维度引用；不直接引用原始尾帧，也不能并行生成依赖尚未完成实片的下一段。

## 资产制作补全

缺资产时先交付具体资产设计与制作提示词：稳定资产键、原文依据、身份／时期／造型、可见特征、材质、用途、参考文件和验收条件。已有合格素材复用；仅缺少可逆环境细节时由基准补足，不把所有普通物件升级为必需独立参考。

用户要求制作资产且有相应工具时执行已授权的图片／声音制作；需额外付费或工具不可用时交付待制作清单，不宣称已生成。新人物以造型参考为主要交付，不额外默认生成独立肖像；检查各视图的脸、发型、服饰、身形和关键饰物一致，不把多视图拼图直接当视频第一帧。场景参考交代入口、锚点、人物行动空间及反向机位关系；道具记录正反面、尺度和剧情所需破损状态。声音制作使用用户提供或获准使用的声音来源，不默认克隆他人音色。

第一帧／新制关键帧仅在任务需要且工具支持时制作；它须已包含正确站位、道具和光线。跨段续生成需要的连续性关键帧优先直接从前段最终采用实片中选取或截取，不另造一张未经实片验证的站位图；一张不能同时说清时可分为站位关键帧和背景关键帧。画面内已有的外观信息不在运动指令里反复矛盾描述。具体生成工具按当次可用能力调用，不依赖外部旧Skill路径。

## 正文压缩与精确文字

每镜有一个主要动作目标及明确终态；动作与镜头运动分别说明，避免同一镜同时固定、推进、环绕。重要约束排序：身份与起始状态 → 关键行动／对白 → 反应与结束状态 → 必要摄影。工作稿与平台正文使用[权威提示词框架](prompt-framework.md)；平台存在长度限制时保留信息完整的适配正文并记录派生关系，不能丢对白。

屏幕、文件等关键文字建立准确原文与可读时长。能用已核验图像参考稳定表现时优先使用；无法保证准确时，设计可替换干净画面、记录文字与位置，交接待合成项。不能把后期才能完成的证据文字标成制作完成；本流程不执行叠字合成和剪辑，用户要求完全不依赖后期时须重新设计可直接生成且能传达同一事实的方案，无法做到就明确缺口。

## 回修与成本

失败先分因：剧情／导演、参考资产、平台填写、模型执行、声音、增强或下载。修复对应层，不每次整集推倒重来。给出具体失败时间点、影响和最小替代方案，保留原版本。

提交次数和预算仅取用户授权或项目已确认上限；未授予重试时不自动付费重试。已授权多次尝试则每次记录剩余次数、费用、改动变量和结果，到上限停止；同一失败连续两次仍无改善时先改方案或报告阻塞，不消耗剩余预算盲抽。状态不明先查队列，防止重复提交。
