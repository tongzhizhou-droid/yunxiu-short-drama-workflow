# xjd 对峙与揭露写法

仅在用户明确指定 `xjd` 风格，或明确要求这种“动作—拒绝—反应—身份逐步揭露”的对峙写法时读取。它只改变导演表达，不改变原文、资产、连续性、[权威提示词框架](prompt-framework.md)或授权边界。

## 核心写法

- 先识别人物此刻想从谁那里得到什么，再用可见的接近、停顿、拒绝、收回或让路表现关系变化。
- 关键接触写清“想碰／已碰／被躲开／已松手”的阶段；不能把试图拉手直接写成已经牵住，也不能下一镜无故恢复接触。
- 对白保持原话与顺序。说话者、听者反应和短回应可以交替，但同一句只发声一次，不为模仿范例编造金句。
- 群众反应用于表现信息扩散：通常先由少数人听懂，再带出整体安静或骚动；避免所有人机械同步震惊。
- 重要人物可按“局部线索／背影 → 旁人识别 → 完整亮相”逐步揭露，选实际人物特征，不固定步数，普通人物不拖长出场。
- 过肩、俯视、低视角和门内外切换必须服从实际站位、人物左右与轴线；镜头数按叙事需要决定，不继承范例的人物、台词、资产或固定镜数。

自审时重点检查：每镜是否产生新信息、动作或反应；拒绝与接触是否有完整过程；身份揭露是否有铺垫和现场反馈；群众反应是否重复；音效是否对应画面事件。
