# 英文剧本翻译流程

用户提交英文剧本并要求翻译时，执行本流程。单纯翻译不代表授权改编、分镜、平台填写或付费生成。

## 输入与范围

- 阅读用户当次指令和英文原稿，确认实际提供的文件及范围；剧本可以是本项目 `input/剧本` 中的文件，也可以是用户本次附上的文件。
- 完整翻译所有已提供内容，保留标题、章节顺序、场景与叙述段落、人物关系、事件因果、语气及对白信息。不擅自删节、续写或修正剧情。
- 对话、旁白和叙述均翻译成自然中文。专名在全文统一；原文刻意区分的姓名、称呼、昵称和身份不得混同。

## 对照稿

- 默认交付 Word（`.docx`）中英对照稿。每个原文段落在上，对应中文译文紧接其下；不可排成左右双栏。
- 保留英文原文，不用中文替换原文。章节标题也按原顺序呈现。
- 文首提供清晰的章节目录；章节数较多时，目录项目链接至相应章节，方便定位。
- 逐段核对中英文对应关系，避免漏译、重复、错序、错配说话人或把一段译文挂到相邻段落。

## 原稿疑点

- 翻译期间检查原稿的前后矛盾、疑似笔误、明显事实问题及乱码、缺字等无法确定内容。
- 将疑点以醒目的“原稿疑点”短注放在相关中译段落之后，指出章节或相矛盾的段落及具体原因。疑点注释与译文正文清楚区分。
- 只说明有根据的问题；语义不确定时标作“疑似”或说明不能确定，不把推断写成原文事实。
- 忠实翻译原稿，不在正文里暗中替作者改错或补齐缺失情节。用户另行要求润色、校订或改编时，再按其范围处理并标明改动。
- 无法辨认的内容在对应位置标注“原文乱码，无法辨认”；不猜写内容。保留可辨认的原文片段供对照。

## 输出与边界

- 将交付文件保存到项目 `output`，使用能识别剧名与“中英对照”的文件名；原始附件和输入文件保持不变。
- 回复中提供文件链接，并简述标出的主要问题或无法辨认之处。
- 翻译任务完成后停止于文字交付；除非用户明确提出，不自动进入剧本制作、翻拍、分镜、资产处理、平台操作或视频生成。
