# 输出、状态与归档记录

本页供[生成与交付阶段](../skills/yunxiu-delivery/SKILL.md)按需读取，用于续做、查错和证明实际交付范围。

## 推荐文件

| 文件 | 至少记录 |
|---|---|
| `output/第XX集_输入检查.md` | 已读资料、范围、缺项、假设、可继续阶段 |
| `output/第XX集_分镜稿.md` | 唯一权威提示词、版本、段镜、声画时间与起止状态 |
| `output/第XX集_逐段计划.json` | 来源版本／指纹、段号、原镜号、秒数、资产键和起止状态 |
| `output/第XX集_自审.md` | 审查版本、镜号证据、修正、复查和放行范围 |
| `output/第XX集_平台操作结果.md` | 真实 URL／ID、正文与 `@`、参数、费用、同页核对、生成状态 |
| `output/第XX集_下载归档.json` | 采用版本、下载路径、大小、哈希、时长、分辨率、增强状态 |

视频建议命名：`第XX集_段号_卡ID_版本_状态.mp4`。同名文件不静默覆盖；旧版移入明确的历史目录或保留版本后缀。

## 状态必须分开

以下状态分别记录，不可用一个“完成”代替：

- 本地稿已写／已自审；
- 平台资产已入库／卡内已引用／正文真实 `@`／同页已核对；
- 生成已提交／已完成／采用版本已确定；
- 静帧检查／动态观看／声音试听；
- 实片可用／受限可用／需回修；
- 增强已授权／已提交／已完成／增强后已复查；
- 下载已完成／本地文件已校验。

提示词、截图、任务回执、缩略图或单帧都不能证明完整实片通过；无法播放或试听时只记录已核实的部分。

## 归档校验

- 下载后确认路径存在、文件非零且可读；实测容器、宽高、帧率、时长和音轨，必要时记录字节数与 SHA-256。
- 增强件需单独记录来源版本、授权、显示费用、任务结果，以及增强后的画面、声音、时长、伪影和连续性复查。
- 续段先记录前段最终采用版本的尾部观察，再记录所选站位／背景关键帧的时码、文件、用途、镜号和禁用范围。尾部观察不是生成参考，原始尾帧不直接引用。
- 自动抽帧时保留 `manifest.json`，记录源视频路径／版本、SHA-256、实测参数、候选时间点、质量警告、人工采用结果及改名后的对应关系；自动排名不能代替人工验收。
- 续做前核对最新权威稿、平台真实 ID、队列、历史版本、采用版本、授权余量和本地文件；不把外部提交或旧项目状态归因于本流程。

项目配置只保留跨文件索引、授权和当前摘要；逐段细节放在对应输出记录，避免同一状态在多处维护成不同版本。

## 当前索引

项目配置保留稳定事实，逐段当前版本统一索引于 output/当前状态.md。旧状态留在单集历史记录；用户反馈按反馈回修模板逐项关闭设计、同步和实片问题。
