# 分镜自审

先读[云袖总入口](../../SKILL.md)、项目配置、原文、连续性记录、资产映射、当前权威稿、[导演阶段](../yunxiu-director/SKILL.md)、[导演与自审细则](../../references/design-review.md)及[统一验收标准](../../references/acceptance.md)。有旁白或后期配音时再读[旁白画面规则](../yunxiu-director/references/narration-visuals.md)。

输出 `output/第XX集_自审.md`，记录审查版本、范围、具体段号／镜号、证据、问题、修正、复查结果、未解决项与放行范围。可由同一助手换审稿视角执行，不强制另开任务。

## 审查维度

| 维度 | 必须成立 |
|---|---|
| 原文与因果 | 行动、对白、转折、结果与说话人可定位；反应不依赖尚未知情的事实 |
| 连续性 | 起止站位、朝向、视线、持物、接触、动作阶段与空间轴线成立；补镜同时检查两侧 |
| 连续性参考 | 尾部只用于确认状态；下一段引用的是从实片选取的站位／背景关键帧，逐张有用途与禁用范围，不直接引用原始尾帧 |
| 观看顺序与表演 | 每次切镜有信息或情绪理由；刺激、反应、行动与落点清楚，不靠侧面多人中景或机械快切掩盖缺镜 |
| 声画时间 | 对白、保留旁白、关键动作和证据阅读有足够时间；估时与实测分开，不为固定秒数截词或加速 |
| 资产与正文 | 造型、场景、道具、音色与使用镜号对应；参考维度受限，无关素材不误绑，正文符合权威提示词框架并与逐段计划同版 |
| 可生成性 | 每段身份、空间、精确文字、对白、接触与运镜负担可控；平台能力未核实时写假设，不写已实现 |

## 回修与放行

- 回到最小合适层级：单镜表达／引用局部修提示词；镜头无法实现则重做该镜；因果、节奏或镜序问题回到场景节拍；身份、场景基准或整体风格错误回到资产／制作基准。
- 修正后重读受影响镜头与前后接点；实质改稿同步权威稿、逐段计划与自审版本。相同矛盾两轮仍无法解决时，写明所需用户选择，不无限重写或硬标通过。
- 结论只能是“通过／通过并保留非阻塞建议／需回修／待资料”，并标注有效范围。只有格式、秒数和资产齐全，不足以放行情绪不准或镜头衔接不清的稿件。
- 自审只证明文字设计在指定范围成立；不证明成片表演、动作、声音、口型或连续性已通过。
