# 剧梦平台填写

先读[云袖总入口](../../SKILL.md)、项目配置、已审稿及版本、资产映射、[权威提示词框架](../../references/prompt-framework.md)、当次真实目标链接与逐段秒数。具体 UI 定位、入库、建卡、富文本 `@`、时长、同页核验、断续与创建项目见[平台操作细则](../../references/platform.md)。

本阶段默认执行到“同页填写完成”。用户明确要求生成时，仍只把真实节点、参数、费用与当前状态交[生成与交付](../yunxiu-delivery/SKILL.md)；本阶段不点击付费按钮。

## 必须成立

- 使用可见的 GPT/Codex 内置浏览器，操作前显示实际剧梦制作页。默认自由模式、自动放入资产、每集独立项目、每段独立空白卡；当次明确变更优先。
- 优先复用项目配置中已确认目标；核对域名、项目、剧集、选中卡与真实 ID。链接、顺序号、旧标题和旧缩略图不代表当前选中对象。
- 资产库入库、卡内引用、正文真实 `@` 和保存核对是四个独立状态。重名资产必须通过缩略图／预览与身份核对，不默认选第一项。
- 正文先保留权威框架的四条开场基调，再填写“素材引用”。每项先插入平台真实 `@` 节点，紧接建议名称、类型、使用镜号、用途与禁用范围。普通 `@名字`、文件名或仅有引用条带都不算真实绑定。
- 跨段连续性图像只绑定已审稿中从前段实片选取的站位／背景关键帧，每张有独立用途；不上传或绑定原始尾帧。已审稿与此冲突时退回导演与自审，不在平台现场擅改。
- 每卡按权威稿的设计总时长单独设置；不固定为4秒或15秒，不沿用上一卡。当前 UI 不支持时，记录差异并退回导演／自审调整，不截断声音或现场猜值。
- 逐卡在同一编辑页核对项目／剧集／真实卡ID、标题、全文、原声顺序、真实节点的身份与位置、卡内引用、模型、参考方式、画幅、分辨率、时长、费用和余额。同页通过不宣称跨页或刷新后持久化已通过。

任一关键节点身份不唯一、真实 `@` 菜单不可用、页面状态不明、目标卡无法确认或已审稿存在实质冲突时，停止依赖范围并记录证据；不用刷新、重建正文或重复上传猜测状态。

写入 `output/第XX集_平台操作结果.md`：稿版本、真实 URL／ID、资产映射、入库／卡内引用／正文 `@` 状态、同页核对、设计／已选秒数、显示费用、生成状态、证据和下一步。没有实际证据的字段写“未确认”。
