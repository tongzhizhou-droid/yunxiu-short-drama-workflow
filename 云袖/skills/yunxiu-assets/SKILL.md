# 输入预检与资产映射

先读[云袖总入口](../../SKILL.md)、项目配置、本次连续性记录、[真人审美与表演](../../references/visual-performance.md)。文件可读性、剧本范围、压缩包／表格／OCR、定稿判定及补件处理见[资料与资产预检](../../references/preflight-assets.md)。

输出 `output/第XX集_输入检查.md`，包含来源与版本、集数范围、可读性、资产映射、必需缺项及影响、非阻塞建议、结论和有效范围。

## 执行

- 先按原文与连续性列出现场人物、年龄／时期／服装、场景、关键道具、发声角色与后续必需项；不只看当前镜头。
- 实际查看图片、声音和文件内容，不凭文件名、文件夹存在、颜色标记或“已上传”推定定稿与可用。
- 人物默认使用已确认造型图，不另导入独立肖像；场景、道具、音色按剧情需要映射。角色图背景不自动算场景，图中人物不自动算现场角色。
- 每项记录稳定资产键、真实路径、用途、身份／造型、查看依据、已核验／未核验状态。用户已接受的替代素材记录差异与适用范围，不重复确认。
- 旁白音频与角色音色参考分开；声纹样音不能代替本集旁白的句子和时长。需切气口时读[旁白音频处理](../yunxiu-director/references/narration-audio.md)。
- 用户要求制作缺失资产且授权、工具均满足时，按[生成设计](../../references/generation-design.md)执行；否则只交付缺项与具体制作规格。

剧本或关键资产缺失／不可读时，停止依赖它的创作与平台工作；用户已明确允许部分范围时，只放行资料齐全部分。本阶段通过只代表本地输入与资产可用，不代表已上传、已引用或已生成。
