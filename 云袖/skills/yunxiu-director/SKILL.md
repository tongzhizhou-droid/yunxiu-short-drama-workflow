# 导演设计与提示词

先读[云袖总入口](../../SKILL.md)、项目配置、原文、连续性记录、资产映射、[权威提示词框架](../../references/prompt-framework.md)和[生成设计](../../references/generation-design.md)。镜头组织、表演、对白、节奏、手机／屏幕、出场、儿童伤病与自审细则见[导演与自审细则](../../references/design-review.md)；需选摄影手法时读[镜头手法](references/camera-techniques.md)。

输入须包含前后状态、可用资产和平台能力假设。续段还须有前段最终采用实片的尾部状态检查，以及从该实片选取的站位／背景关键帧。缺少时先回到[剧情连续性](../yunxiu-story-continuity/SKILL.md)。

输出：

- `output/第XX集_分镜稿.md`：唯一权威正文，实质修改递增版本。
- `output/第XX集_逐段计划.json`：来源稿版本／指纹、段号、原镜号、`seconds`、起止状态、资产键与用途。
- 旁白覆盖表与有序对白清单，放在工作稿而非平台生成正文。

## 执行

1. **先定声画时间。** 旁白以完整保留为起点，逐句建立原文、音频版本／估时、画面覆盖与起止时间；只在用户要求精简时删减。有旁白时读[旁白画面规则](references/narration-visuals.md)；用户提供音频时读[切气口与校时](references/narration-audio.md)。
2. **再按事件分段。** 在完整语句、动作落点或时空转换处划分生成段；不按固定秒数或固定镜头数拆卡。高风险交接不在接触中途切断。
3. **组织平台正文。** 逐字保留权威框架的四条开场基调，再依次填写“素材引用 → 前情提要 → 人物站位 → 剧情描述 → 镜头1—N”。不另加旧版“视觉前缀／声音要求”栏目，不为填满镜头14制造空镜。
4. **对齐时间与状态。** 每镜写起止时间、景别／机位／必要运镜、可见动作、简洁情绪与视线、对白／必要声音、与下镜相接的动作状态。时间码连续，合计与逐段计划及拟设平台时长一致。

## 必须保留的写法

- 素材引用每项写“编号 ＋ 真实 `@` 节点／待绑定标记 ＋ 建议名称 ＋ 类型 ＋ 使用镜号 ＋ 用途 ＋ 禁用范围”。本地名称不代替平台真实绑定。
- 跨段只引用从前段实片选取的站位／背景关键帧，且每张只控制已标注维度；不直接引用原始尾帧，不照搬其景别、机位或构图。
- 权威框架的四条开场基调逐字沿用；只有用户当次明确改写时才覆盖。
- 原文对白保持原语言、原话、说话人与顺序；长台词可在反应镜头中画外连续，但每个词只说一次，不截断、重复或加速。
- 情绪用简洁状态、动作、视线、语气和刺激后反应表达；不堆五官肌肉描写，不用无刺激的同步反应。
- 人物位置、视线、接触、持物和动作阶段通过可见过程改变；不跳轴、不重演已完成动作、不让道具瞬移或换手。
- 平台正文默认无旁白、内心独白、背景音乐和字幕；工作稿仍要为后期旁白保留相关画面与时长。

用户指定快切、半句后推镜、指定关键帧拉远、屏幕播放层级、表情纠错或合并补镜时，再读[用户反馈落实](../../references/user-feedback-workflow.md)。

用户明确指定 `xjd` 风格时，再读[xjd 对峙与揭露写法](../../references/xjd-style.md)；未点名时不按题材自动套用。

交稿前核对原文覆盖、说话人、声音时长、站位、持物、身份、集尾及资产用途，然后交[分镜自审](../yunxiu-review/SKILL.md)；创作者自称通过不算复查。
