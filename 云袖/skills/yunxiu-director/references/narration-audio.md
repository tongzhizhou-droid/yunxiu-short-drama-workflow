# 可选：旁白音频自动切气口与时间校对

在用户流程第2步“旁白取舍与画面对应”中选择使用音频后执行。接收用户提供的本地文件或附件，不把“发送旁白”理解为向第三方发送。沿用用户本次选择；未选择时提供“发送音频实测／暂不提供、先估时”的选项。没有新音频时不自动处理历史文件。

## 输入与顺序

先依据[旁白取舍规则](narration-visuals.md)确定信息单元和最终保留稿。用户可以提供全长旁白或已精简的旁白；全长音频先映射原句；当前优先保留更多旁白，以完整保留可用原句为起点，仅对用户已确认删减的部分标不使用。新要求覆盖旧精简方案时同步恢复相应声音与画面，不能固守已失效的删句结论。核对集数、角色、语言、版本及文件可读性，保留原文件，不覆盖。

执行顺序：读取音频与实际时长 → 对齐原语言文本 → 检测候选气口 → 按完整语义校正切点 → 输出独立音频段 → 试听校对 → 回写旁白与画面对应表。

## 自动切分与校对

1. 使用实际可用的本地媒体工具读取采样率、声道、时长并检测停顿；有可用转写／强制对齐工具时得到句词时间。记录工具与检测参数，按噪声底和说话方式调整，不把固定静音阈值当通用标准。
2. 静音、换气、句末与语义边界结合判断；气口不等于每次呼吸都要切，也不等于自动删光所有静音。连读、低声词、尾音及情绪停顿须保留，无可信气口时保持长段，不在词中间硬切。
3. 候选切点保留适量自然起音、尾音和呼吸余量，按实际听感调整；相邻源区间不能重复或漏掉词。独立片段的边缘余量单列，不把多段余量误算为连续旁白正文时长。
4. 依据最终保留稿导出新的独立片段，沿用原采样率和声道，优先无损WAV；不变速、不拼接整集、不自动去除有表现意义的呼吸。被画面替代的句子保留来源记录，标“不用于旁白”，不混入保留片段清单。修改后无对应录音的文字标待重录，不能剪接出原音频没有的话。
5. 逐段试听并对照原文及切点前后，校对漏词、重复、错词、截音、说话人及情绪停顿。转写结果是定位辅助，不能反过来修改原剧本。没有试听或可靠对齐能力时，只交候选切分及元数据实测，明确“文本／切点未校对”，不宣称完成自动校对。
6. 校验每段文件实际时长、可读性和源区间；默认以保留呼吸及边缘余量的完整导出时长安排覆盖，若只采用其中一部分，必须明确有效区间。逐句对应画面与语义落点，不能只核对总长度。

## 输出与交接

按本项目输出习惯保存，例如 output/旁白/第XX集/版本/N01.wav，配套时间表可用JSON或CSV；不硬编码项目名。至少记录：信息编号、角色、原文及最终保留文本、源文件版本／指纹、源起止秒、导出文件、导出实测秒数、有效发声区间、保留呼吸及余量、保留／不使用／待重录状态、对应镜号和校对结论。

源时间、导出片段内时间与计划画面时间分开记录；完整音频中段间空白被保留还是不进入新版，必须可追踪。改动切点或文字后更新版本、重测受影响片段，并同步权威稿与分段计划。

切气口属于本次允许的旁白音频预处理，不扩展为视频剪辑或最终混音。工具缺失时明确缺的是解码、切分、转写／对齐还是试听能力；可以继续不依赖它的画面设计，但精确声画时长保持待校对，不伪造完成。不得擅自把音频上传外部服务或启动付费服务。
