# 镜头手法参考

用户于2026-09-28确认可吸收《文转剧1.7对白旁白加强.txt》中的镜头手法。本页仅整理摄影与镜头衔接方法，不引入该资料的旁白删改、强制碎镜、输出格式、表情或音效规定。

## 使用原则

先确定观众此刻需要看到的人物、信息或关系变化，再选手法。对白与情绪段仍以单人近景、过肩反打、关键特写和固定机位为基础；不为展示技巧增加时长。每镜优先一种主要运镜，写清起点、方向、落点及可见内容，不只写术语。组合手法按动作与信息节点拆镜；连续摄影才能写在同一镜号中。

以下用途是可选表达，不是手法与情绪的一一对应公式。既有轴线、视线、前段实片尾部所确认的实际状态、已选站位／背景连续性关键帧、正常动作速度、自然表演及项目光线要求优先。跨段同人物仍须形成明显景别或视角差异，不得因参考图而直接复制尾帧构图。

## 景别、视角与构图

| 手法 | 适用目的与写法要点 |
|---|---|
| 全景／大全景 | 建立地点、行动路线或人物与环境的关系；空间信息读清后转向当前主体，不以远景拖长人物出场。 |
| 中景 | 看清走位、距离、接触与交接；信息完成后按情绪主体切近。 |
| 近景／特写／局部大特写 | 承载情绪转折、关键台词或证据；明确面部、手部或物品的具体可见范围，不机械逢名词就特写。 |
| 主观视角 | 呈现角色实际能看到的线索；建立观看者及视线方向，不让人物提前看见未知事实。 |
| 过肩 | 表达对话和关系；写清越谁哪侧肩看谁、前景位置和主体视线，主体面部无遮挡。 |
| 平视／仰视／俯视 | 按人物关系和空间选择观看高度；不把仰拍固定等同强者、俯拍固定等同弱者。极端角度须保留人物与动作可读性。 |
| 顶视／斜角 | 顶视用于空间格局，斜角可用于明确的失衡感；仅在叙事需要时使用，不能代替角色表演。 |
| 三分／中心／对称 | 安排主体与空间秩序；重要人物正式亮相沿用主位清楚的要求。 |
| 前景遮挡／框架构图 | 用门框、肩背等建立关系、纵深或受限视野；保留脸部、关键动作和证据的可见通道。 |
| 引导线／留白 | 用环境线条引向主体，或用主体周围空间表达距离与孤立；不能让关键表演小到难以辨认。 |

## 焦点与运镜

| 手法 | 适用目的与执行边界 |
|---|---|
| 浅景深／大景深 | 分别用于突出主体或同时保留多个空间层次；需要读清的证据与人物不能被无意虚化。 |
| 焦点转移 | 同一连续镜头内，从已知主体转到新线索或反应人物；写清前后景位置、起始焦点、触发点和终点。 |
| 推近／后撤 | 推近强调具体信息或情绪变化，后撤揭示环境或关系；写明何时开始、结束景别，不惯性缓慢推镜。 |
| 摇镜／横移 | 沿视线寻找目标、揭示相邻人物或展示空间关系；写出运动方向及落点，不与硬切混称。 |
| 跟拍／侧移跟拍／低机位跟拍 | 跟随有信息的行动；保持行进方向、人物距离与路线，不完整展示无信息路程。 |
| 小幅弧线／半环绕 | 随人物关系变化揭示另一侧信息；明确运动范围与轴线，避免无动机绕人和背景突变。 |
| 手持感 | 在追逐、慌乱等情境下适量使用；保持面部、动作与空间可读，不给普通对白统一加晃动。 |
| 急变焦／甩镜／滑动变焦（Dolly Zoom） | 仅用于明确需要的突发信息或主观冲击；描述实际画面变化，不能只堆名称。滑动变焦须同时协调机位移动与焦距变化，作为复杂手法单独评估。 |
| 高空／俯冲／穿障／完整环绕 | 用于确需展示空间或运动路线的场景；先检查遮挡、人物身份、路径与模型执行负担，必要时拆成明确镜头。不能承诺模型必然完成。 |

速度渐变、极慢动作和高频变焦不作为常规节奏方法；仅在具体风格或剧情需要且不破坏对白与动作时间时选用。柔焦、特殊光色或回忆滤镜依项目要求决定，不随“回忆”自动添加。

## 镜头衔接

- 动作匹配：写清前镜动作阶段与后镜接续状态，保持方向、手别、持物和空间关系；跨时空匹配须另有清楚的时空转换依据。
- 遮挡衔接：规划前景遮满画面的时刻与下一镜起幅；遮挡本身不保证防跳轴或无变形，仍检查前后位置与动作。
- 形状／构图匹配：在有意义的两个对象间设计相似形状、位置或运动方向，避免让观众误认成同一物件或连续事件。
- 甩动／缩放／旋转衔接：仅在确有风格需要时规划运动方向与落点，不强制每镜添加转场。需要剪辑才能实现的效果标为后期方案，本流程不执行剪辑，也不宣称已完成。

## 交稿检查

逐镜确认：新增了什么可见信息；主体是否清楚；运动能否在声音与动作所需时长内完成；与前后镜的轴线、视线和动作是否相接。写不出具体目的时回到固定机位或直接切镜。实际效果须经实片检查，不能以术语齐全代替验收。
