# 云袖 AI 真人短剧工作流

这是一个可复制的新项目模板，用于把已有剧本推进到剧情连续性、资产核验、导演分镜、自审、剧梦平台填写，以及在明确授权后的生成与交付。

仓库只保存工作流、阶段 Skill、规则和空白模板，不包含任何具体剧目的剧本、人物、场景、旁白、视频、平台链接、余额、生成记录或成片。

## 开始使用

1. 复制或克隆本仓库，并重命名为剧名。
2. 把项目资料放进 `input` 和 `旁白` 的对应目录。
3. 填写 `项目配置.md`。
4. 从 `云袖/SKILL.md` 开始，按当次任务选择所需阶段。

详细目录说明见 `使用说明.md`，执行边界见 `AGENTS.md`。

## 默认安全边界

- 素材、旁白、视频、输出和临时文件默认被 Git 忽略，避免误上传具体剧目内容。
- 未收到当前项目、当前范围的明确授权，不提交生成、增强或其他付费动作。
- 跨段连续性以已采用实片的实际尾部状态为准；原始尾帧只用于判定状态，下一段引用另选的站位／背景关键帧。
